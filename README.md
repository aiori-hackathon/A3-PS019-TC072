### Problem Statement: AIORI-3 PS019
Automated Personal-Data Discovery & Privacy Evidence Inventory Framework

---

## Executive Overview
NDEMS is a centralized framework designed for tamper-evident digital evidence management, privacy auditing, and regulatory compliance under DPDPA guidelines. The architecture integrates cryptographic integrity verification with automated metadata tracking to ensure end-to-end chain of custody.

## Core Technical Features
- Cryptographic Hashing: SHA-256 integrity proofs for uploaded digital records
- Tamper-Evident Logs: RFC 3161 compliant timestamping for non-repudiation
- Privacy-First Audit Engine: Continuous personal data mapping aligned with DPDPA frameworks
